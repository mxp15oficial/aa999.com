## 🚀 Funcionalidades

- ✅ Redirecionamento automático em 3 segundos
- ✅ Botão manual para ir agora
- ✅ Design moderno e responsivo
- ✅ Interface amigável

## 📋 Como funciona

1. Usuário acessa o app
2. Uma página bonita é exibida com spinner de carregamento
3. Após 3 segundos, redirecionamento automático ocorre
4. Usuário pode também clicar no botão "Ir agora" para redirecionar imediatamente
